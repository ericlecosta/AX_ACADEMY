# Portal Fake - Automação de Solicitações de Cadastro (Avaliação 2)

Projeto de Hyperautomation desenvolvido para automatizar o processo de recebimento, análise e organização de solicitações de cadastro encaminhadas por e-mail.

## Objetivo

O projeto tem como objetivo utilizar Python e RPA para automatizar etapas do processo de cadastro do Portal Fake, reduzindo atividades manuais, organizando as solicitações recebidas e proporcionando maior agilidade e padronização no tratamento das demandas.

## Funcionamento

O processo automatizado realiza, de forma geral, as seguintes etapas:

1. Monitoramento da caixa de e-mail;
2. Identificação de mensagens relacionadas a solicitações de cadastro;
3. Leitura e análise das informações recebidas;
4. Identificação e organização dos documentos encaminhados;
5. Validação das informações e documentos;
6. Registro e organização dos dados da solicitação;
7. Encaminhamento da demanda para a próxima etapa do processo;
8. Atualização do status da solicitação.

## Tecnologias

- **Python**
- **Automação Web**
- **IMAP / E-mail**
- **Git e GitHub**
